# はじめに

`Golash` は、モダンな文法と厳密なエラー検出を備えた処理系です。

主な特徴は以下のとおりです。

* 同一バイナリで CUI と GUI を完全自動判定して動作します。
* 定数は変数への代入で表します。
* `include` / `dll` / `dlldef` でファイルと DLL 関数を宣言できます。
* レジスタ型VMでコンパイルして動作します（中間ファイルを生成しません）。
* `if` や `while` などの条件式は整数です（`0` は偽、非0は真）。`true` は `1`、`false` は `0` の糖衣構文です。
* 日本語テキストは rune 単位で扱い、日本語も 1 文字として数えます。
* 文字列は `s[i]` で rune 単位の1文字を読み出せ、`repeat` でも1文字ずつ反復できます。
* 配列は参照セマンティクスを持ちます。
* GUIでは描画、入力、音声、ウィジェットなどの機能を利用できます。

# インストールとビルド方法

## 必要環境

Go 1.25 以上が必要です。

## ビルドとテスト

```sh
cd golash
go build ./...
go test ./...
```

コマンド名 `gsh` のバイナリを作る場合は、出力名を指定します。
単一バイナリで CUI / GUI の両方が動作します。

```sh
go build -o gsh .          # Linux / macOS
go build -o gsh.exe .      # Windows
gsh run examples/falling.gsh
```

> `TestGuiRender` など一部のGUIテストは Ebiten の制約により、1プロセスにつき1回だけウィンドウを生成します。2回目以降は自動的にスキップされます。

---

# コマンドの使い方

```text
gsh run <file.gsh> [-- args...]   スクリプトを実行します
gsh repl                                            対話環境（REPL）を起動します
gsh lex <file.gsh>                                  字句トークン列を表示します
gsh parse <file.gsh>                                構文木（AST）を表示します
gsh disasm <file.gsh>                               バイトコードを表示します（VM用）
gsh build <file.gsh> [-o out.exe]                   単一exeを生成します
gsh help                                             ヘルプを表示します
```

レジスタVMバックエンドでコンパイルして実行します。
`GOLASH_TRACE=1` でVMの命令トレースを標準エラー出力します。

## `gsh run`

```sh
gsh run examples/falling.gsh
```

スクリプトを実行します。

### コマンドライン引数

ファイル名の後に `--` を置くと、その後ろをスクリプトの引数として取得できます。

```sh
gsh run main.gsh -- hello world
```

スクリプト側では `args()` で取得します。

`-` から始まる引数は `--` の後に記述してください。GUIビルドで `--` より前に指定されたオプション形式の引数はエラーになります。

### ファイルの関連付け（ビルドした exe をダブルクリックで開く）

`gsh build` した exe にファイルを関連付けると、そのファイルをダブルクリックしたときに exe が起動し、パスが `args()` の先頭に入ります（例：`main.exe "C:\work\foo.gsh"` → `args()` は `["C:\\work\\foo.gsh"]`）。スクリプト側で先頭を開けば、エディタ等の関連付け起動が作れます。Windows では対象ファイルを右クリック→「プログラムから開く」→ exe を選択します。

## 実行モードの自動判定

実行モードを指定する宣言はありません。`gsh run` / `gsh build` は常に自動判定です
（REPL は常に CUI）。

- `screen` / `gfxsel` / `button` など GUI 専用の組込みが main から到達可能な
  コードにあれば GUI、なければ CUI になります。
- 呼ばれない関数の中の GUI 呼び出しは判定に含みません（GUI ヘルパを
  含むライブラリを CLI ツールから include しても CUI のままです）。
- 判定は静的な到達可能性です。条件分岐の内側にある GUI 呼び出しも、
  その関数が呼ばれていれば GUI 側に倒れます。
- GUI 専用処理を CLI テストから呼ぶと GUI 判定になります。CLI テストは
  GUI 組込みを呼ばないようにしてください。
- `mode` は通常の識別子として使えます。

## `gsh repl`

REPLを起動します（常に CUI）。

```sh
gsh repl
```

以下のいずれかで終了します。

```text
exit
:quit
:q
```

括弧 `(`、角括弧 `[` が閉じられていない場合や、ブロックが `end` で閉じられていない場合は、継続プロンプト `>>` が表示されます。

## `gsh lex`

字句解析結果を確認します。

```sh
gsh lex examples/falling.gsh
```

## `gsh parse`

構文木（AST）を確認します。

```sh
gsh parse examples/falling.gsh
```

## `gsh disasm`

レジスタVMのバイトコードを確認します（定数プール・名前表・レジスタ数・
ソース位置付き）。

```sh
gsh disasm examples/falling.gsh
```

## `gsh build`

スクリプトをコンパイルし、ランタイムにバイトコードを連結した
単一exeを生成します（Windows は exe 末尾の余分なデータを無視するため、
連結したまま実行できます）。

```sh
gsh build examples/falling.gsh
./falling.exe
```

- 出力先の既定はスクリプトと同名の `.exe`（`-o` で変更可）。
- 自動判定の結果はビルド時に解決して記録する。
  残りの引数はすべてスクリプト引数（`args()`）になる。
- 相対パスの基準は exe のあるディレクトリ。
- 生成 exe にさらに `build` しても多重連結にならない（入替え）。
- 出力先に書けない場合（実行中の exe への上書きは Windows が錠をかけて不可）は `名前_new.exe` に出してその旨を知らせる。使うには終了後にリネームする。
- GUI モードの exe はコンソールなし（windowsgui）で出す。ダブルクリック起動で黒いコンソールが開かなくなり、それを閉じたときに同コンソールの全プロセス（本体＋実行した子）が道連れに終了する事故が起きない。CLI モードの exe は端末用にコンソール付きのまま。

## DLL呼び出し（`dll`/`dlldef`）＋直接配列引数

C ABI の DLL を呼び出します。CGO 不要で Windows/Linux/macOS 共通です。
高速化したい処理や OS の機能を、外部 DLL に切り出す用途です。
呼び出しは one-way（スクリプト→DLL。コールバックは v1 の対象外）。
公開 API は `dll`/`dlldef` 宣言のみです。
配列は `dim(n)` などで作った通常の配列をそのまま渡します。

```text
dll "user32.dll"
dlldef winmsgbox "MessageBoxA" "int(int,string,string,int)"
r = winmsgbox(0, "本文", "標題", 0)
```

- `dll "path"` は以降の `dlldef` が対象にする DLL を指定します（include ツリー共有で、最後に有効だったものが勝つ）
- 相対パスの DLL は、スクリプトのディレクトリ、次にカレントディレクトリの順で実在するものを探します。どちらにも無い名前（`user32.dll` などのシステム DLL）は OS の検索に任せます
- `dlldef NAME "symbol" "sig"` は `sig` に従って呼んで戻り値を返します。
  引数は15個まで。存在しない関数・個数不一致・型不一致は日本語エラーです
- 署名は `"戻り値(引数1,引数2,...)"` の形です。型は下表の7種です

| 型 | 意味 |
| --- | --- |
| `int` | C int（32bit。範囲外はエラー） |
| `float` | C double |
| `string` | UTF-8＋NUL終端（呼び出し中のみ有効） |
| `bool` | `int` の別名（互換用。`0`=false、非0=true） |
| `int[]` | int 配列を i32 連続バッファとして渡す（長さは別引数で渡す。呼び出し中のみ有効。空配列は NULL） |
| `float[]` | 数値配列を f64 連続バッファとして渡す（int 要素は昇格。長さは別引数で渡す。呼び出し中のみ有効。空配列は NULL） |
| `void` | 戻り値なし（戻り値の型にのみ使用可） |

`int[]` / `float[]` は呼び出し時に連続バッファへ写してポインタを渡し、
DLL が書き込んだ内容は呼び出し後に元の配列へ書き戻します。
出力バッファとして使う場合は、あらかじめ `dim(n)` などで要素数を確保してください：

```text
dll "mylib.dll"
dlldef fillbuf "fill_buffer" "int(int[],int)"
buf = dim(256)
n = fillbuf(buf, 256)
```

呼び出しは式のまま値を返します（特別な変数は要りません）。
行番号は保たれる。引数の個数は署名から決まります。同じパスの DLL は開き直さず共用し、プロセス終了まで保持します。
- `dlldef` より前に対象の `dll` が無いとエラーです。重複定義・キーワード・`true`/`false`・組込み関数と同名は使えません

高速化は DLL 呼び出しを使ってください。

# 字句構造

## 文の区切り

`Golash` では、文を**改行**で区切ります。

```
x = 10
y = 20
msg(x + y)
```

セミコロン `;` は使用できません。

```
x = 10;   // エラー
```

文の区切りには改行を使用してください。

---

## コメント

```
// コメントです
msg("hello")
```

`//` から行末までがコメントです。ブロックコメント（`/* */`）はありません。

---

## 識別子とキーワード

識別子は次の形式です。

```text
[A-Za-z_][A-Za-z0-9_]*
```

次のキーワードは識別子として使用できません。

```text
def if elseif else end repeat while switch case default
as break continue return local
true false
```

---

## 空白

以下は基本的に無視されます。

* スペース
* タブ
* `\r`

改行 `\n` は文の区切りとして意味を持ちます。

# リテラルと基数表記

## 整数リテラル

整数は `int64` の範囲で扱います。

`-9223372036854775808`（最小値）のみ、括弧なしの単項マイナスで記述できます（正の `9223372036854775808`・`0x8000000000000000` 単体は範囲外エラーです）。

| 種類   | 表記          | 例           | 10進値 |
| ---- | ----------- | ----------- | ---: |
| 10進数 | なし          | `42`, `007` |   42 |
| 16進数 | `0x` / `0X` | `0xFF`      |  255 |
| 2進数  | `0b` / `0B` | `0b101`     |    5 |
| 8進数  | `0o` / `0O` | `0o17`      |   15 |

プレフィクスの大文字・小文字は区別されません。

```text
0xab == 0XAB
```

字句解析時に10進数へ変換されるため、パーサや実行系は元の基数を意識する必要がありません。

`gsh lex` や `gsh parse` でも10進数として表示されます。

---

## 整数の使用例

```
msg(0xFF)          // 255
msg(0b101 & 0b011) // 1
msg(0o10 | 1)      // 9

x = 0x10
msg(x * 2)         // 32
```

---

## 不正な基数リテラル

| ソース                    | エラー                                    |
| ---------------------- | -------------------------------------- |
| `0x`                   | `malformed hexadecimal literal`        |
| `0b`                   | `malformed binary literal`             |
| `0b2`                  | `malformed binary literal`             |
| `0o8`                  | `malformed octal literal`              |
| `0xg`                  | `malformed hexadecimal literal`        |
| `0x1p3`                | `malformed hexadecimal literal`        |
| `0xFFFFFFFFFFFFFFFFFF` | `hexadecimal literal out of range`     |
| `0x1.5`                | `hexadecimal floats are not supported` |

アンダースコアによる桁区切りは使用できません。

```
0xFF_FF   // 非対応
```

数字に `_` や英字を直接続けること（`1_000`、`123abc`）、小数点の後に数字がないこと（`3.`）は字句エラーになります。

---

## 浮動小数リテラル

次の形式が利用できます。

```text
3.14
.5
2e3
1.2E-4
```

指数部には `+` または `-` を付けられます。

```text
2e+3
2e-3
```

基数プレフィクス付き浮動小数は非対応です。

範囲外の値（`1e999` など）はパースエラーになります（`Inf` にはなりません）。

---

## 文字列リテラル

文字列はダブルクォートで囲みます。

```
"hello"
"こんにちは"
```

シングルクォートは使用できません。

利用できるエスケープは以下です。

```text
\"
\\
\n
\t
\r
\0
```

未知のエスケープ、文字列中の改行、閉じられていない文字列はエラーになります。

生のNULバイトはソースのどこにも書けません（字句エラー。`\0` エスケープを使用してください）。

---

## true / false

`true` は整数 `1`、`false` は整数 `0` の糖衣構文です。独立した `bool` 型はありません。

```
true   // 1
false  // 0
```

---

## 配列リテラル

```
a = [1, 2, 3]
b = []
c = [[1, 2], [3, 4]]
```

配列はネストできます。

要素の型は混在可能です（voidは要素にできません）。

```
a = [1, "hello", true]
```

末尾のカンマも利用できます。

```
a = [1, 2, 3,]
```

---

# 型と値

`Golash` の値には次の4種類があります。関数は値ではありません（`def` で名前を登録し、呼び出しにのみ使用します）。値を返さない結果はvoidであり、代入・引数・演算に使うとエラーになります（`msg()` / `print()` は黙って飛ばします）。

| 型          | 説明             | 例            |
| ---------- | -------------- | ------------ |
| `int`      | 64bit符号付き整数    | `42`         |
| `float`    | 64bit浮動小数      | `3.14`       |
| `string`   | 文字列            | `"hello"`    |
| `array`    | 可変長配列          | `[1, 2]`     |

`true` / `false` は整数 `1` / `0` の糖衣構文です。真偽を返す関数・比較・論理演算も `int` の `1` / `0` を返します。

## intとfloat

比較・等価判定では `int` と `float` を自動的に比較できます。

```
msg(10 == 10.0)  // 1
```

---

## 配列の参照セマンティクス

配列は同じ実体を共有します。

```
a = [1, 2, 3]
b = a

b[0] = 99

msg(a[0])  // 99
```

---

## 文字列アクセス

文字列は rune 単位で添字アクセスできます。返る値は1文字の文字列です。

```
s = "あいう"
msg(s[0])  // あ
msg(s[1])  // い
```

添字は `0` 以上で長さ未満である必要があります。負数・範囲外はエラーです。

文字列は不変なので、`s[0] = "x"` のような代入はエラーになります。

# 演算子と優先順位

## 演算子一覧

| 分類  | 演算子                                  | 説明                    |
| --- | ------------------------------------ | --------------------- |
| 算術  | `+ - * / %`                          | 加減乗除・剰余               |
| ビット | `& \| ^ ~ << >>`                     | AND・OR・XOR・NOT・左/右シフト |
| 比較  | `== != < <= > >=`                    | 等価・不等価・大小比較           |
| 論理  | `&& \|\| !`                          | 論理積・論理和・論理否定          |
| 代入  | `= += -= *= /= %= &= \|= ^= <<= >>=` | 代入・複合代入               |
| その他 | `[...] (...)`                      | 配列・関数呼び出し       |

---

## 優先順位

数字が小さいほど優先順位が高くなります。

| 優先度 | 演算子               | 結合 |
| --: | ----------------- | -- |
|   1 | `()` `[]`     | 左  |
|   2 | `-` `!` `~`       | 右  |
|   3 | `*` `/` `%`       | 左  |
|   4 | `+` `-`           | 左  |
|   5 | `<<` `>>`         | 左  |
|   6 | `<` `<=` `>` `>=` | 左  |
|   7 | `&`               | 左  |
|   8 | `^`               | 左  |
|   9 | `\|`              | 左  |
|  10 | `==` `!=`         | 左  |
|  11 | `&&`              | 左  |
|  12 | `\|\|`            | 左  |

ビット演算は等価比較より強く結合します。

```
a & b == c
```

は、

```
(a & b) == c
```

として解釈されます。

したがって、

```
if flags & 0xF0 == 0x10
end
```

は意図どおりマスク判定として利用できます。

---

## ビット演算

ビット演算は整数にのみ使用できます。

```
msg(6 & 3)      // 2
msg(6 | 3)      // 7
msg(6 ^ 3)      // 5
msg(~5)         // -6
msg(1 << 4)     // 16
msg(256 >> 3)   // 32
```

`float` や `string` に対して使用すると実行時エラーになります。

シフト数は `0`～`63` の範囲で指定してください。

```
-8 >> 2   // -2
```

`>>` は算術右シフトです。

---

## 整数演算の範囲

`int` の `+` `-` `*`・単項 `-`・`<<` は64bitでラップします（Goと同様）。

```
msg(9223372036854775807 + 1)  // -9223372036854775808
```

例外は `abs(MinInt64)` のみで、エラーになります（絶対値が表現できないため）。

## 文字列の結合

`+` は、左右どちらかが `string` の場合、両辺を文字列化して結合します。

```
msg("n=" + 42)      // n=42
msg([1, 2] + "")    // [1, 2]
```

void値の結合はエラーです（`"a" + f()` は `"anull"` になりません）。

## 比較の型規則

* `==` / `!=`：`int` と `float` は自動比較、他は同種のみ比較（異種は `0`、エラーではありません）
* `<` `<=` `>` `>=`：数値同士または文字列同士のみ対応（他はエラー）。結果は `1` / `0` です
* 整数除算は0方向へ切り捨てます（`-7 / 2` は `-3`）。剰余の符号は被除数に従います（`-7 % 3` は `-1`）
* 比較の連鎖（`1 < 2 < 3` など）は左結合です。`(1 < 2) < 3`、つまり `1 < 3` と評価されるため、数学的な連鎖にはなりません

## NaN・無限大

`NaN` と `±Inf` は値として存在しません。リテラルに書けず、以下のいずれもエラーになります。

* `0` による除算・剰余（`float` の `0.0` を含む）
* `sqrt()` の負数、`log()` の `0` 以下
* 有限でない計算結果（`1e308 * 10`、`exp(1000)`、`pow(-1, 0.5)` など）
* `float("nan")` / `float("inf")` などの変換、`int()` の範囲外変換

---

# 式

式には次の要素を使用できます。

* リテラル
* 変数参照
* 配列リテラル
* 括弧
* 単項演算
* 二項演算
* 関数呼び出し
* 配列アクセス
* 文字列アクセス（`s[i]`）

例：

```
x = (1 + 2) * 3
msg(arr[0])
msg(max(10, 20))
```

---

## 短絡評価

`&&` と `||` は短絡評価を行います。

```
false && something()
```

では右辺は評価されません。

論理演算子の左右は整数です。`0` は偽、非0は真として扱い、結果は `1` / `0` になります。

```
1 && true    // 1
2 && 3       // 1（両方とも真）
0 || 5       // 1
```

# 文

## 変数宣言と代入

```
local x = 42
name = "Alice"
arr = [1, 2, 3]
arr[0] = 99
```

左辺には次を指定できます。

* 変数
* 配列要素

トップレベルでは、通常の代入がグローバル変数を更新し、なければ宣言します。`local` は関数内でのみ使用でき、トップレベルではエラーです。

関数内で新しいローカル変数を作るには `local name = 式` が必要です。`local` は同名のグローバルがあっても必ず関数ローカルになり、その宣言以降はグローバルを隠します。`local` なしの代入は、既存のローカル（引数・`local` 宣言済み）またはグローバルを更新します。どちらも存在しない名前への代入は未定義エラーです。

```
def example()
    local v = 1      // 関数ローカル
    v = 2          // ローカルの更新
    global_value = 3   // 既存グローバルの更新
end
```

`local` の初期値は必須です。

組み込み関数と同名への宣言・代入はエラーです（`local msg = 1` や `msg = 1` は不可。`def` と同じ規則）。

複合代入も利用できます。

```
x = 0
x += 1
x &= 0xFF
x <<= 2
```

複合代入では左辺のアドレスは1回だけ評価されます（`a[next()] += 1` の `next()` は1回だけ呼ばれます）。

* トップレベルでの代入はグローバル変数を更新し、なければ宣言します
* 関数内で新しいローカルを作るには `local` が必要です。`local` は同名グローバルを隠します
* `local` なしの代入は既存のローカル／グローバルを更新し、どちらもなければ未定義エラーです
* `if` / `repeat` / `switch` / `while` の中身はスコープを作らないため、その中の `local` も関数ローカルになります。`repeat` の変数はループの間だけローカルです
* 関数の引数と `repeat` のカウンタ・要素変数は暗黙にローカルです
* 同じスコープへの再代入は上書きです（`repeat` の中の代入も毎回動きます）
* 組込み関数と同名への宣言・代入はエラーです（`msg = 1` は不可）
* `let` は通常の識別子です（変数名に使用できます）

## 式文

式だけを独立した文として記述できます。

```
msg("hello")
x + 1
```

値を使用しない場合でも文として有効です。

---

## if

```
if x > 0
    msg("positive")
elseif x == 0
    msg("zero")
else
    msg("negative")
end
```

条件式は整数です。`0` は偽、非0は真です。

```
if 1        // 常に真
end
if 0        // 常に偽
else
end
```

条件分岐の連鎖は `elseif` と記述してください（単一の `end` で閉じます）。

```
if x == 1
elseif x == 2
else
end
```

## repeat

### 回数指定

```
repeat 5
    msg("hello")
end
```

### カウンタ付き

```
repeat 3 as i
    msg(i)
end
```

表示される値は、

```text
0
1
2
```

です。

### 配列・文字列指定

```
arr = ["a", "b"]
repeat arr as x
    msg(x)
end
```

文字列を指定すると、1文字ずつ順番に反復します。

```
repeat "あい" as ch
    msg(ch)
end
```

### インデックス付き

```
arr = ["a", "b"]
repeat arr as i, x
    msg(str(i) + ":" + x)
end
```

結果：

```text
0:a
1:b
```

文字列でも同じ形で、`i` は rune 単位の添字、`ch` は1文字の文字列です。

```
repeat "あい" as i, ch
    msg(str(i) + ":" + ch)
end
```

### 仕様

* 整数は `0` 以上である必要があります。
* 配列を指定すると要素を、文字列を指定すると rune（1文字）を順番に反復します。
* `as x` の `x` は各要素・各文字のコピーです。
* `as i, x` の `i` は添字、`x` は要素・文字です。
* カウンタ変数はループ内でのみ有効です。
* カウンタは読み取り専用です。
* 配列要素の変更は元の配列には書き戻されません。
* 配列を変更する場合は `a[i] = ...` を使用してください。
* 反復回数はループ開始時に確定します。
* ループ中の `push()` によって反復回数は増えません。
* 整数の `repeat` では `as i, x` は利用できません。
* ネストしたループで同じ変数名を使うと、内側の変数が一時的に外側を隠します。

## while

```
i = 0

while i < 5
    msg(i)
    i = i + 1
end
```

条件が非0（`true` は `1`）の間、繰り返します。

```
while true
    // 無限ループ
end
```

ループを抜けるには `break` を使用します。

---

## switch

```
switch x
    case 1, 2
        msg("one or two")

    case 3
        msg("three")

    default
        msg("other")
end
```

仕様：

* 検査対象の式は1回だけ評価されます。
* `case` は複数の値をカンマで指定できます。
* `default` は最大1個です。
* `default` の位置は自由です。
* フォールスルーはありません。
* 最初に一致した `case` だけ実行されます。
* 比較は `==` / `!=` の等価判定です。
* 配列は同一実体のときのみ等しくなります（深い比較はしません）。
* `int` と `float` は自動的に比較可能です。
* `case` 値のvoidはエラーです（検査対象と対称）。

---

## break / continue

```
repeat 10 as i
    if i == 5
        break
    end

    if i == 2
        continue
    end

    msg(i)
end
```

### `break`

`repeat`、`while`、`switch` を終了します。

### `continue`

`repeat`、`while` の次の周回へ進みます。

`switch` 内で発生した `continue` は、外側のループへ伝播します。

ループ外の `break` / `continue` はエラーになります。

また、関数呼び出しをまたいで伝播することはありません。

意図的な中断には `assert(false, msg)` を使います。

---

## return

```
def max(a, b)
    if a > b
        return a
    end

    return b
end
```

`return` は関数内でのみ使用できます。

値を省略した場合はvoidを返します（使用箇所でエラーになります）。

```
return
```

## 関数定義

```
def greet(name)
    msg("Hello, " + name)
end

def add(a, b)
    return a + b
end

greet("Alice")
msg(add(1, 2))
```

`def` はトップレベルにのみ記述できます。関数は値として扱えません（代入・引数・`vartype` 等では変数未定義エラーになります）。呼び出し時はグローバル変数を参照できます。

パラメータの重複、組み込み関数と同名の定義・パラメータ、および同名関数の再定義はエラーになります。引数の個数は厳密に一致する必要があります。

関数内で新しいローカル変数を作るには `local name = 式` が必要です。`local` は同名のグローバルを宣言以降隠します。`local` なしの代入は、引数・`local` 宣言済みローカル・既存グローバルのいずれかを更新し、どれもなければ未定義エラーです。ブロック（`if` / `while` / `repeat` / `switch`）は専用スコープを作りません（`repeat` の変数のみ例外）。

再帰呼び出しは深さ10000が上限です（超過は実行時エラー）。構文のネスト（ブロック・括弧・配列/呼び出しの入れ子）は1000が上限です（超過は構文エラー）。

# 組み込み関数

## 組み込み関数の読み方

以下の表では、すべての関数について同じ形式で記述します。

| 項目      | 内容            |
| ------- | ------------- |
| 関数      | 関数名と引数        |
| 説明      | 関数そのものの意味     |
| GUIでの挙動 | GUIモードで何が起こるか |
| CUIでの挙動 | CUIモードで何が起こるか |

### 表中の表現

* **共通**：GUI / CUI で同じ意味です。
* **GUIのみ**：GUI専用機能です。
* **CUIのみ**：CUI側の機能です。
* **非対象**：その環境では意味を持ちません。
* **未定義**：環境差が明文化されていない部分です。

# 10.1 出力・文字列化

| 関数                      | 説明                       | GUIでの挙動                | CUIでの挙動               |
| ----------------------- | ------------------------ | ---------------------- | --------------------- |
| `msg(v)`                | 値を文字列化して改行付きで出力します（単一引数。voidは改行のみ）。配置後は自動で改行し、カレント位置も次行へ移します | 文字グリッドへ改行付きで表示します | 標準出力へ改行付きで表示します |
| `print(v)`              | `msg` と同じ形式で、最後に改行を付けません（単一引数。voidは無出力） | GUI上の文字出力として表示します（末尾の改行なし。文中の改行文字では改行します） | 標準出力へ改行なしで表示します       |
| `strf(format, args...)` | printf形式で文字列を生成します       | GUI / CUIとも文字列を返すだけです  | GUI / CUIとも文字列を返すだけです |
| `str(v)`                | 値を `msg` と同じ形式で文字列化します   | GUI / CUIとも文字列を返します    | GUI / CUIとも文字列を返します   |
| `vartype(v)`            | 値の型名を返します                | GUI / CUIとも同じ文字列を返します  | GUI / CUIとも同じ文字列を返します |

GUI では `msg()` / `print()` の文字は `pset()` / `line()` / `rect()` などの図形と
同じキャンバス（`gfxsel(id)` で選んだ描画バッファ）へ描かれます。重なりは呼び出し順で
決まるため、`msg()` の後に `rect()` すればその範囲の文字は隠れ、`rect()` の後に
`msg()` すれば文字が図形の上に乗ります。`cls()` は文字と図形を
まとめて消し、カーソルがウィンドウ下端を越えると文字と図形が一緒に1行分
スクロールします。

`strf()` の対応指定子：

```text
%d
%f
%s
%x
%c
%%
```

# で始まる行を含むソースは字句エラーになります。ファイルの事前診断は字句解析（Golash の `lex.gsh`）の結果に `file:` を付けて行います。

# 10.2 文字列操作

| 関数                                       | 説明                         | GUIでの挙動        | CUIでの挙動        |
| ---------------------------------------- | -------------------------- | -------------- | -------------- |
| `len(s)`                                 | rune数で文字数を返します             | 同じです。日本語も1文字です | 同じです。日本語も1文字です |
| `slice(s, start [, end])`                | 指定範囲 `[start, end)` の部分文字列を複製します（配列にも使えます。10.9参照） | 同じです           | 同じです           |
| `find(s, sub [, start])`                 | 部分文字列の位置を返します（配列にも使えます。10.9参照） | 同じです           | 同じです           |
| `strtrim(s [, chars] [, mode])`          | 両端の文字を除去します                | 同じです           | 同じです           |
| `split(s, delim)`                        | 区切り文字で分割して配列を返します          | 同じです           | 同じです           |
| `replace(s, old, new)`                   | `old` の出現をすべて `new` に置換します | 同じです           | 同じです           |
| `upper(s)`                               | 大文字化します（Unicode対応。日本語は変化しません） | 同じです           | 同じです           |
| `lower(s)`                               | 小文字化します（Unicode対応。日本語は変化しません） | 同じです           | 同じです           |
| `getpath(path [, mode])`                 | パスをビットフラグで分解・変換します（`1` 拡張子除去 / `2` 拡張子のみ / `8` ディレクトリ除去 / `16` 小文字化 / `32` ディレクトリのみ。加算で組合せ。`0`・省略時は全体） | 同じです           | 同じです           |
| `strwidth(s)`                            | 表示幅を返します（自作エディタの caret 配置用） | 現在のフォントでのピクセル幅を返します（`\t` は半角4文字分） | rune 数を返します |
| `asc(s)`                                 | 先頭文字のコードポイントを返します            | 同じです           | 同じです           |
| `chr(code)`                              | コードポイントの1文字を返します             | 同じです           | 同じです           |

文字列は `s[i]` で rune 単位の1文字を読み出せます（読み取り専用。`s[0] = "x"` はエラー）。`repeat s as i, ch` でも同じ単位で反復します。

### `slice`

```
slice(s, start [, end])
slice(arr, start [, end])
```

`start` と `end` が負数の場合は末尾から数えます。`end` は終端（排他的）で、省略時は末尾までです。

文字列は rune 単位、配列は要素単位です。文字列は新しい文字列、配列は新しい配列を返し、元の配列は変更しません。

負数を末尾基準に正規化した後、`0 <= start <= end <= 長さ` を満たさない範囲は、黙って切り詰めずエラーになります。`start == end` は空（`""` または `[]`）を返します。

### `find`

```
find(s, sub [, start])
find(arr, v [, start])
```

`start` 以降で最初に一致する位置を返します。見つからない場合は `-1` を返します。

文字列は rune 単位の絶対インデックス、配列は要素の添字です。`start` が負数または長さ超過の場合はエラーです（黙って0扱い・`-1` にはなりません）。`start` を省略すると `0` から探します。

### `strtrim`

`mode`：

|   値 | 動作   |
| --: | ---- |
| `0` | 左右両方 |
| `1` | 左のみ  |
| `2` | 右のみ  |

`chars` を省略すると空白（Unicode空白）が対象です。`mode` 指定時は `chars` も必須です（`(s, mode)` の2引数形はありません）。

### `upper()` / `lower()`

Unicode の大文字・小文字変換です。日本語は変化しません。

### `asc()` / `chr()`

```
asc("A")
```

は `65` を返します。GUI `input()` の制御文字（Backspace はコード `8`）にも使え、`asc(input()) == 8` で判定できます。空文字列はエラーです。

```
chr(65)
```

は `"A"` を返します。サロゲート・範囲外はエラーです。

### `getpath`

`mode` は HSP 準拠のビットフラグを加算で組み合わせます。省略時は `0`（全体）です。

| 値   | 意味                |
| ---: | ----------------- |
| `0`  | 全体（コピー）          |
| `1`  | 拡張子除去             |
| `2`  | 拡張子のみ（ドット付き）    |
| `8`  | ディレクトリ除去（ファイル名） |
| `16` | 小文字化（修飾子）        |
| `32` | ディレクトリのみ         |

例: `1` で拡張子なしフルパス、`9`（`1+8`）で拡張子なしファイル名、`8` で拡張子付きファイル名、`2` で拡張子のみ、`32` でディレクトリ部分、`16` との組合せで小文字化します。未知のビット・負値はエラーです。複数の部位が重なる場合は `32` > `2` > `8` > `1` の優先順で、`16` は結果に適用します。

# 10.3 数値・数学

| 関数                       | 説明                   | GUIでの挙動 | CUIでの挙動 |
| ------------------------ | -------------------- | ------- | ------- |
| `int(v)`                 | 整数へ変換します             | 同じです    | 同じです    |
| `float(v)`               | 浮動小数へ変換します           | 同じです    | 同じです    |
| `abs(v)`                 | 絶対値を返します（最小整数はエラー） | 同じです    | 同じです    |
| `sqrt(v)`                | 平方根を返します             | 同じです    | 同じです    |
| `sin(v)`                 | 正弦を返します              | 同じです    | 同じです    |
| `cos(v)`                 | 余弦を返します              | 同じです    | 同じです    |
| `tan(v)`                 | 正接を返します              | 同じです    | 同じです    |
| `atan(y)` / `atan(y, x)` | 逆正接を返します             | 同じです    | 同じです    |
| `exp(v)`                 | `e^v` を返します          | 同じです    | 同じです    |
| `log(v)`                 | 自然対数を返します            | 同じです    | 同じです    |
| `pow(base, exp)`         | 累乗を返します              | 同じです    | 同じです    |
| `limit(v, lo, hi)` | 値を指定範囲に収めます（ちょうど3引数） | 同じです | 同じです |
| `min(a, b, ...)` | 最小値を返します（2個以上） | 同じです | 同じです |
| `max(a, b, ...)` | 最大値を返します（2個以上） | 同じです | 同じです |
| `len(arr)`               | 配列の要素数を返します（`len()` は文字列の長さにも使えます） | 同じです    | 同じです    |
| `rnd(n)`                 | `0` ～ `n-1` の乱数を返します | 同じです    | 同じです    |
| `randomize([seed])`      | 乱数系列を初期化します          | 同じです    | 同じです    |

補足：

* `int(float)` は0方向へ切り捨てます（範囲外・NaNはエラー）。
* `string` は10進整数として解析されます（`"3.9"`・`"1e2"`・`"0x10"` はエラー）。
* `float(string)` は有限値のみ受け付けます（`"nan"`・`"inf"` はエラー）。
* `true` / `false` はそれぞれ整数 `1` / `0` です（`int(true)` は `1`、`float(false)` は `0`）。
* `abs()` は元の `int` / `float` 型を維持します。
* `sqrt()` は負数でエラーになります。
* 三角関数の角度単位はラジアンです。
* `atan(y, x)` は2引数時に `atan2` として動作します。
* `log(0)` および負数はエラーです。
* 有限でない結果（`exp(1000)`、`pow(10, 309)`、`pow(-1, 0.5)` など）はエラーです。
* `limit()` は引数がすべて `int` の場合、結果も `int` です（整数範囲で丸めます）。
* `min()` / `max()` も同様に、全 `int` のときだけ `int` を返します。
* `randomize()` に整数を指定すると再現可能な乱数系列になります。
* 引数なしでは現在時刻を使って初期化します。

# 10.4 時間・実行制御

| 関数                     | 説明                 | GUIでの挙動           | CUIでの挙動           |
| ---------------------- | ------------------ | ----------------- | ----------------- |
| `sleep(ms)`            | 指定ミリ秒待機します         | 指定時間だけ待機します       | 指定時間だけ待機します       |
| `await([n])`           | `n` フレーム待機します（目標tickが表せない巨大値はエラー） | VSync tick に同期します | 約16ms × `n` 待機します |
| `tick()`               | フレームカウンタを返します      | `Update` 回数を返します  | 時刻 ÷ 16ms を返します   |
| `nanotime()`           | 単調増加するナノ秒カウンタを返します | 同じです              | 同じです              |
| `gettime(type)`        | 現在時刻の各要素を返します（下表の `0`～`7`） | 同じです              | 同じです              |
| `exit([code])`          | プログラムを終了します        | ウィンドウ処理を終了します     | プログラムを終了します       |
| `assert(cond [, msg])` | 条件が偽ならエラーにします      | 同じです              | 同じです              |

### `await()`

```
await()
```

は1フレーム待機します。

```
await(3)
```

では3フレーム待機します。

ゲームループなどでは、単純な `sleep(16)` より `await()` の使用が推奨されます。

GUIでは `await()` / `sleep()` はフレーム境界として扱われます。その時点までに
`cls()` / `msg()` / `print()` で作ったテキストと、`pset()` / `line()` /
`rect()` / `ellipse()` / `tri()` / `gfxquad()` / `gfxcopy()` 等の図形描画および `gfxsel(id)` の
切替がまとめて画面へ反映されるため、`cls()` の直後や描きかけ・裏バッファの
途中状態が1フレーム表示されることはありません（ちらつき防止）。この意味で
`await(0)` は「今のフレームを確定して表示する」操作になります。`await()` /
`sleep()` を一度も使わないスクリプトではフレーム境界が無いため、
毎フレームの内容がそのまま反映されます。
CUIでは出力が逐次表示されるため、この差はありません。

### `gettime()`

| `type` | 意味 |
| --: | ---- |
| `0` | 年 |
| `1` | 月（`1`～`12`） |
| `2` | 曜日（`0` 日曜～`6` 土曜） |
| `3` | 日 |
| `4` | 時 |
| `5` | 分 |
| `6` | 秒 |
| `7` | ミリ秒 |

範囲外の `type` はエラーです。`nanotime()` はプロセス起動からの単調増加ナノ秒です（NTP等で戻りません）。

# 10.5 コンソール・端末操作

| 関数                | 説明                | GUIでの挙動                                 | CUIでの挙動                 |
| ----------------- | ----------------- | --------------------------------------- | ----------------------- |
| `cls()`           | 画面をクリアします         | 描画対象バッファ（`gfxsel(id)` の対象。文字と図形の両方）をクリアします。ウィジェットは残ります（消去は `objdel()` のみ） | 端末出力画面をクリアします           |
| `color()`         | 現在の文字色を取得します       | 現在の文字・図形描画色を `[r, g, b, a]` の配列で返します | 現在の文字色を `[r, g, b, a]` で返します（端末はαを描画しません） |

| `input([prompt])` | 入力を読み取ります | GUIは即時モード（`input()` の即時モードを参照。引数不可）。CUIは行単位のブロッキング入力です | 標準入力から1行読み取ります |

| `logmsg(args...)` | エラー出力へメッセージを出力します（void引数は黙って飛ばします） | デバッグ用のエラー出力へ出力します                       | 標準エラー出力へ出力します           |

```text
GUI : ピクセル
CUI : 文字セル
```

# 10.6 プロセス・環境

| 関数                    | 説明                 | GUIでの挙動                  | CUIでの挙動                  |
| --------------------- | ------------------ | ------------------------ | ------------------------ |
| `exec(name, args...)` | 外部コマンドをコンソールなしで非同期に起動します | 起動したら `0` を返してすぐ戻ります（終了は待ちません）。入出力は透過的に表示します。子にコンソールを作りません（黒窓が出ず、親子の道連れ終了もありません）。入出力は継承しますが取り込みはしません。 | 同じです |
| `pipeexec(name, args...)` | 外部コマンドを実行し `[終了コード, 標準出力, 標準エラー]` の配列で返します | 終了まで待ちます（標準入力は切り離し）。非0終了も値です。起動失敗は `[-1, "", メッセージ]` です（エラーにしません）。 | 同じです |
| `procopen(name, args...)` | 非同期プロセスセッションを開始し `[pid, エラー]` を返します | 子にコンソールを作りません（Windows は `CREATE_NO_WINDOW`）。stdin/stdout/stderr はパイプ | 同じです |
| `procread(pid)`       | 子の未読出力（stdout+stderr）を取り出します | 非ブロッキング。無ければ `""` | 同じです |
| `procwrite(pid, s)`   | 子の stdin へ書き込みます   | 成功で `1`、終了済み・失敗で `0` | 同じです |
| `proceof(pid)`        | 子の stdin を閉じます       | 成功で `1`                | 同じです |
| `procpoll(pid)`       | 子の状態を `[実行中, 終了コード]` で返します | 終了コードは実行中 `-1`       | 同じです |
| `procclose(pid)`      | セッションを終了・回収します | 実行中なら kill し、終了コードを返します | 同じです |
| `env(name [, v])`   | 環境変数の取得・設定を統合します（`v` があれば設定、なければ取得） | 同じです（取得は未設定時に `""`。設定は現プロセスと子プロセスに反映します） | 同じです                     |
| `open(target)`        | ファイル・フォルダ・URLを開きます | OSの関連付けアプリで開き、待機しません     | OSの関連付けアプリで開き、待機しません     |

`env(name)` は未設定時に `""` を返します。

`exec()` は起動成功で `0` を返してすぐ戻ります（非同期。終了コードは返しません）。出力の取り込み・終了待ちが要る場合は `pipeexec()` を使い、`r = pipeexec(name, ...)` の `r[0]`・`r[1]`・`r[2]` で終了コード・標準出力・標準エラーを値で受けます（失敗しても止まりません）。

`procopen()` は対話用です。毎フレーム `procread()` で出力を拾い、`procwrite()` で入力を送れます。GUI エディタのコンソールペインはこれを使っています。

```gsh
p = procopen("gsh", "run", "game.gsh")
if p[0] >= 0
    while true
        out = procread(p[0])
        if out != ""
            msg(out)
        end
        st = procpoll(p[0])
        if st[0] == false
            break
        end
        await()
    end
    code = procclose(p[0])
end
```

| 用途 | 使う関数 |
| ---- | ------- |
| 終了コード・標準出力・標準エラーを値で扱いたい | `pipeexec()` |
| 終わらない処理を裏で走らせたい | `exec()` |
| 対話的に入出力したい | `procopen()` 系 |

# 10.7 クリップボード・OSダイアログ

| 関数                  | 説明                 | GUIでの挙動           | CUIでの挙動                           |
| ------------------- | ------------------ | ----------------- | --------------------------------- |
| `clip([s])`   | クリップボードのテキスト取得・設定を統合します（`s` があれば設定、なければ取得） | OSクリップボードから取得／へ設定します  | OSクリップボードから取得／へ設定します                  |
| `dialog(text [, mode])` | OSのメッセージボックス／ファイルダイアログを表示します | OSネイティブのダイアログを表示します | 同じです（OSネイティブのダイアログを表示します） |

`dialog` は OS のネイティブ API を使います。GUI/CUI のどちらからも同じダイアログが開きます。

| mode | 表示 | 戻り値 |
| --: | --- | --- |
| `0` | 標準メッセージボックス + [OK]（省略時） | `1` |
| `1` | 警告メッセージボックス + [OK] | `1` |
| `2` | 標準メッセージボックス + [はい][いいえ] | はい=`1`、いいえ=`0` |
| `3` | 警告メッセージボックス + [はい][いいえ] | はい=`1`、いいえ=`0` |
| `4` | ファイルを開くダイアログ | 選択パス、キャンセル時 `""` |
| `5` | ファイルを保存ダイアログ | 選択パス、キャンセル時 `""` |

メッセージボックスのタイトルは `Golash` です。`0`〜`3` の `text` は本文、`4`/`5` の `text` は次の形式のフィルタです（`""` ならすべてのファイル）。

```text
"画像|*.png;*.jpg"
```

保存先のファイルが既に存在する場合、OS のダイアログが上書き確認を出します。

ダイアログの初期フォルダは、スクリプトの置かれたディレクトリ（存在する場合）、なければカレントディレクトリです。GUI/CUI いずれのモードからも同じOSダイアログが開きます。

* タイムアウトは10秒です。

# 10.10 ファイル・ディレクトリ操作

パス引数の解決順序：絶対パスはそのまま使います。相対パスはスクリプトファイルのあるディレクトリを先に探し、なければカレントディレクトリを探します（`include` と同じ規則。REPLではカレントディレクトリのみ）。存在しないパスへの保存はスクリプト脇に作ります。`exec` / `pipeexec` のコマンド名はPATH解決のため対象外です。

ディレクトリ系の組込は、場所の取得を `<修飾語>dir`、ディレクトリ操作を `dir` + 動詞で統一しています（`curdir` / `exedir` / `homedir` / `tmpdir`、`dirlist` / `dirmake`）。

| 関数                          | 説明                  | GUIでの挙動 | CUIでの挙動 |
| --------------------------- | ------------------- | ------- | ------- |
| `fileinfo(path)`             | ファイルの情報を `[サイズ, 更新時刻, ディレクトリか]` の配列で返します（存在しなければ `[-1, 0, 0]`。ディレクトリなら `1`、ファイルなら `0`） | 同じです。サイズはバイト数、更新時刻は Unix ミリ秒、ディレクトリのサイズはOS依存です。更新時刻は `fileinfo(path)[1]`（存在しなければ `0`）、存在確認は `fileinfo(path)[0] != -1` で行います | 同じです |
| `dirlist([mask])`           | ファイル名一覧を取得します       | 同じです    | 同じです    |
| `filedel(path)`              | ファイルを削除します          | 同じです    | 同じです    |
| `dirmake(path)`             | ディレクトリを1階層作成します     | 同じです    | 同じです    |
| `curdir([path])`            | カレントディレクトリの取得・変更を統合します（`path` があれば変更、なければ取得） | 同じです    | 同じです    |
| `filecopy(src, dst)`           | ファイルをコピーします         | 同じです    | 同じです    |
| `txtfile(path)`             | テキストファイルを読み込みます（`\r\n` は `\n` に正規化） | 同じです | 同じです |
| `txtfile(path, s)`          | テキストをファイルへ保存します | 同じです | 同じです |
| `binfile(path)`             | ファイルをバイト配列（0-255 の整数）として読み込みます | 同じです | 同じです |
| `binfile(path, arr [, size])` | バイト列をファイルへ保存します。`size` は配列の先頭から書き込むバイト数です | 同じです | 同じです |
| `exedir()`                  | 実行ファイルのディレクトリを返します  | 同じです    | 同じです    |
| `homedir()`                 | ホームディレクトリを返します      | 同じです    | 同じです    |
| `tmpdir()`                  | 一時ディレクトリを返します       | 同じです    | 同じです    |

### `dirlist()`

`*` と `?` を含むglobパターンを指定できます。

返される配列はソート済みです。

基準ディレクトリはスクリプトのあるディレクトリです（REPLではカレントディレクトリ）。マスクにディレクトリ部分がある場合は通常の解決順（スクリプト脇→カレント）で探します。

### `txtfile()` / `binfile()`

`txtfile(path)` のテキスト読み込みでは、`\r\n` のみ `\n` に正規化されます（単独の `\r` はそのまま残り、行区切りにもなりません）。

`binfile(path)` はバイト列をそのまま返します。`binfile(path, arr [, size])` の `arr` は 0 から 255 の整数のみを受け付けます。`size` を指定すると配列の先頭からそのバイト数だけを書き込みます。

# 10.11 GUI・ウィンドウ

> このグループはGUI機能を中心とした関数です。

| `closing()`       | ウィンドウ終了要求を調べます  | ×ボタンによる終了要求を取得します      | GUIウィンドウがないためGUI用途の意味はありません |

保存処理などを行った後、

```
exit()
```

で終了してください。

# 10.12 GUI描画

`pos()` は `msg()` / `print()` とウィジェット配置にのみ効きます。図形描画（`pset()` / `pget()` / `line()` / `rect()` / `ellipse()` / `gfxcopy()` / `gfxblit()`）と `gfxquad()` / `tri()` は起点座標を引数で指定します（`pos()` は移動しません）。

| 関数                      | 説明            | GUIでの挙動          | CUIでの挙動             |
| ----------------------- | ------------- | ---------------- | ------------------- |
| `pset(x,y)`             | 1ピクセルを描画します   | `(x,y)` に現在色で1ピクセル描画します   | GUI描画は行われません        |
| `pget(x,y)`             | 1ピクセルの色を取得します | `(x,y)` の色を `0xRRGGBB` 整数（`r*65536+g*256+b`）で返します。範囲外はエラーです | GUI描画は行われません        |
| `line(x1,y1,x2,y2)`     | 直線を描画します      | `(x1,y1)` から `(x2,y2)` へ現在色で直線を描画します     | GUI描画は行われません        |

| `rect(x,y,w,h)`     | 矩形を塗りつぶします    | `(x,y)` を左上として `w x h` を塗ります（負の辺は逆向きに正規化されます）        | GUI描画は行われません        |

# 10.14 キーボード・マウス入力

| 関数               | 説明                   | GUIでの挙動                   | CUIでの挙動                |
| ---------------- | -------------------- | ------------------------- | ---------------------- |
| `getkey(code [, mode])` | キーとマウスボタンの押下状態を返します（`mode` 省略時・0は押されている間、非0は押した瞬間のみ） | `code` 0〜2 はマウスボタン（0 左、1 中、2 右）。それ以外は下表のキーコード。`mode` 省略時・0は押されている間 `1` を返し続けます（消費しません）。非0は押した瞬間だけ `1` になり呼び出しで消費します（同一フレーム内の複数回呼び出しは2回目以降 `0`）。修飾キー `16`/`17`/`18` は左右いずれかで反応します | GUIキーボード・マウス入力がないためGUI用途です |
| `input()`        | 入力された文字を返します（キーリピート付き、即時モード） | `input()` の即時モードを参照（下記）。`inputbox` フォーカス中は `""` です | GUIキーボード入力がないためGUI用途です（CUIの `input()` は行単位です） |

### コード表（キー/マウス）

```text
0～2     マウスボタン（0 左、1 中、2 右）
8        Backspace
9        Tab
13       Enter
16       Shift（左右いずれか）
17       Ctrl（左右いずれか）
18       Alt（左右いずれか）
27       Esc
32       Space
33～36   PageUp・PageDown・End・Home
37～40   左・上・右・下
45       Insert
46       Delete
48～57   0～9
65～90   A～Z
112～123 F1～F12
186～192 ; = , - . / `（US 配列順）
219～222 [ \ ] '
```

`code` に表外の値（例 `3`〜`7`、`999`）を渡すとエラーになります。`mode` は省略時 `0`、指定時は整数のみです（文字列はエラー）。

`getkey()` の使い分け：移動など押し続けたい場合は `getkey(39)`（`mode` 省略・0）、回転・決定など1押下で1回だけ反応させたい場合は `getkey(90, true)`（`true` = 1）を使います。後者は `was_*` フラグの自前管理なしで立ち上がりだけを検出できます（呼び出しで消費）。マウスも同じ形です：

```text
if getkey(0, true)
    // 左ボタン押した瞬間
end
if getkey(0)
    // 左ボタン押している間
    // ドラッグ：getkey(0, true) で掴み、getkey(0) が離れるまで追従
end
```

### `input()` の即時モード（GUI）

GUI の `input()` はブロックせず、前回呼出以降に入力された確定文字列を返します（IME確定分を含みます。変換中は画面左上の固定欄に表示されます）。OS のロケール依存変換（配列・shift・caps 対応）で。新しい入力（OS のキーリピートで届く文字や IME 確定分を含む）は届くたびにそのまま返します。何もなければ `""` です。毎フレーム呼び出すことを想定しています。

Backspace・Tab・Enter・Esc・Delete は制御文字（コード `8`・`9`・`13`・`27`・`127`、同じリピート付き）として返るため、`asc()` と組み合わせて行編集が組めます（`"\r"` との比較、または `asc(k) == 13` で確定判定）。矢印・ファンクションキー等の非文字キーは現れません（物理キーは `getkey()` を使います）。

```
s = ""
while true
    k = input()
    if k != ""
        if k == "\r"
            break
        end
        s = s + k
    end
    await()
end
```

リピート間隔（60fpsでの目安）：文字入力は OS のキーリピート設定に従います。Backspace 等の制御文字は初回即時・約400ms後から約33msごとに再送します。

注意：

* GUI の `input()` は引数を取りません（プロンプトは `msg()` で表示してください）
* `inputbox` フォーカス中は `""` です（ボックスがキー所有権を持ちます）
* IME 変換中は制御キーを返しません（変換の編集・確定が優先されます）
* CUI の `input([prompt])` は行単位のブロッキング入力です（EOFは `""` になります）

## GUI入力についての注意

GUI にブロッキングの行入力はありません。`input()` は即時モードです（詳細は `input()` の即時モードを参照）。

* 1行テキスト入力欄が要る場合は `inputbox()` を使います。自前実装でIME変換入力に対応し、フォーカス中はIMEが自動で有効になり（`ime(true)` 不要）、変換中文字列と候補窓は画面左上に固定表示されます。`ime(false)` で強制無効化もできます（次のフォーカスで再有効化）
* `inputbox` を使わない確定文字列の受取は、`ime(true)` 後に `input()` をポーリングします（確定分が順に返ります。変換中は画面左上の固定欄に表示されます）

```
ime(true)
s = ""
while true
    k = input()
    if k == "\r"
        break
    end
    s = s + k
    await()
end
ime(false)
```

# ファイル分割と include

`include` を使用すると、スクリプトを複数ファイルに分割できます。

```
// main.gsh
include "lib.gsh"

msg(greet("Alice"))
```

```
// lib.gsh
def greet(name)
    return "Hello, " + name
end
```

## includeの探索順

以下の順番でファイルを探します。

1. 取り込み元ファイルのディレクトリ
2. カレントディレクトリ
3. 絶対パス

同じ絶対パスは一度しか取り込まれません。複数の場所から同じライブラリを
`include` しても多重定義にはなりません。循環 `include` はエラーです。

エラー位置には元ファイルの名前が保持されます。

```text
file:line:col
```

`include` は行頭の宣言です。`include` で取り込んだファイルの変数 /
`def` は、その `include` 行より後の行から見えます。逆に、親の
後の行の定義が、既に展開済みのライブラリに届くことはありません。

`#` で始まる行は字句エラーになります。ファイル分割は `include`、DLL宣言は `dll` / `dlldef` を使います。定数は変数への代入で表します。実行モードを指定する宣言はなく、自動判定のみです。

# GUIモード

```sh
gsh run program.gsh
```

で実行します（GUI 専用組込みが到達可能なら自動でウィンドウが開きます）。
特別なビルドは不要で、単一バイナリが CUI / GUI の両方に対応します。

GUIモードでは、主に以下の機能が利用できます。

```text
ウィンドウ
描画
キーボード
マウス
ゲームパッド
タッチ
IME
音声
ウィジェット
```

GUI関数については、本マニュアルの「組み込み関数」で各関数ごとにCUIとの違いを記載しています。

# エラー表示とデバッグ

## エラー位置

字句・構文・実行時エラーは、可能な限り次の形式で表示されます。

```text
file:line:col: メッセージ
```

例：

```text
main.gsh:3:5: undefined variable "x"
lib.gsh:10:1: malformed hexadecimal literal
```

`include` されたファイルも、元ファイルとは別のファイル名・行番号で表示されます。

GUIモードで実行時エラーが発生した場合は、メッセージを標準エラー出力へ出したうえでウィンドウを閉じてプロセスを終了します（終了コード `1`）。正常終了時はウィンドウを開いたままにします（`exit()` で閉じます）。

## 主なエラー

| エラー                             | 意味                     |
| ------------------------------- | ---------------------- |
| `semicolons are not allowed`    | セミコロンは使用できません          |
| `condition must be an integer`  | 条件式は整数（0=false、非0=true）である必要があります |
| `operator & requires integers`  | ビット演算は整数にのみ使用できます      |
| `shift count must be 0..63`     | シフト数は0～63である必要があります    |
| `malformed hexadecimal literal` | 16進リテラルが不正です           |
| `cannot open include`           | include先が見つかりません       |
| `circular include`              | 循環includeが検出されました      |

# 実装上のメモ

## アーキテクチャ

処理系はおおむね以下の順番で動作します。

```text
lexer.go
    ↓
include.go
    ↓
parser.go
    ↓
compile.go → vm.go
```

値は `value.go` の `Value` 型（フラットなタグ付き構造体）で表現されます。
VM の命令形式・コンパイル方針の詳細は `docs/DESIGN_VM.md` を参照してください。

入出力などの環境依存部分は、`builtin.go` の `Backend` インターフェースを通じて抽象化されています。

---

## GUIの実装

GUIバックエンドは `gui/` ディレクトリに実装されています。

主な構成：

```text
Ebiten
ebitenui
```

画面描画は `ebiten.Image` へのキューイング方式です。

`ReadPixels` / `WritePixels` はゲームスレッド上で実行されます。

テキスト描画には OS のシステムフォントを使用します（フォントファイルは同梱していません）。

Windows では既定で MS ゴシック（16px で半角 8px・全角 16px のセルグリッドに一致）を、次点で游ゴシック・メイリオ・Noto Sans JP・BIZ UD Gothic などを自動検出します。macOS は Osaka・ヒラギノ角ゴ、Linux は Migu 1M・VL Gothic・IPAゴシック、次点で Noto Sans CJK などを探します。いずれも見つからなければ候補順の次へフォールバックします。

Windows で MS ゴシック・MS 明朝など埋め込みビットマップ（EBLC/EBDT）を持つフォントを使う場合、そのビットマップがあるサイズ（MS ゴシック・MS 明朝は 7〜22px）では `msg()` / `print()` やウィジェット（ボタン・入力欄・リスト等）の文字を GDI でドットのまま描画します（アンチエイリアスなしのくっきりした表示）。ビットマップが無いサイズ・書体は従来通りアウトライン描画です。

環境変数 `GOLASH_FONT` に `.ttf` / `.otf` / `.ttc` ファイルのパスを指定すると、そのフォントを優先します。

`font(spec)` の名前解決順は、スクリプト脇→カレントディレクトリ→システムフォントです。Windows では `C:\Windows\Fonts` に加え、管理者権限なしインストール先の `%LOCALAPPDATA%\Microsoft\Windows\Fonts` も検索します。スクリプト脇・カレントではファイル名そのまま・拡張子補完・前方一致の順で探すので、拡張子なしの指定もそのまま見つかります（例 `PlemolJP`→`PlemolJP-Regular.ttf`）。システムフォントでは拡張子なしの指定を前方一致で探し（同例）、Regular体を優先します。

システムフォントが見つからない環境では、GUI バックエンドの生成時にエラーになります。

音声再生には Ebiten の `audio` パッケージを使用します。

`audio.Context` はプロセス内で1つだけ共有されます。

## IMEの実装状況

IMEによる日本語入力では、変換確定後の文字列は `input()` の即時ストリームまたはフォーカス中の `inputbox` に渡され、変換中の文字列は画面左上の固定欄に表示されます（`ime()` の使い方は 10.16 を参照）。

### 候補ウィンドウ・変換中文字列の位置について

変換中文字列は画面左上隅の固定欄（白地・灰枠・黒文字、変換文節に太下線・他に細下線。縦は1行ぶん＋2px）に、候補窓はその直下の画面左上に固定表示されます（`textinput.Field.HandleInputWithBounds` に渡す矩形基準。Windows `ImmSetCandidateWindow`・macOS・Web のいずれもこの矩形基準）。caret追従・手動の位置指定はありません。

# まとめ：GUIとCUIの使い分け

`Golash` の実行モードは完全自動判定です。GUI 専用組込みが main から到達可能なら GUI、なければ CUI になります。モードを固定する宣言はありません。

```text
CUI
├─ 標準入出力
├─ ファイル・ディレクトリ操作
├─ 文字列操作
├─ 数値計算
├─ 配列
├─ HTTP
├─ プロセス・環境変数
└─ スクリプト制御
```

GUIビルドでは、これに加えて、

```text
GUI
├─ ウィンドウ
├─ 2D描画
├─ キーボード
├─ マウス
├─ ゲームパッド
├─ タッチ
├─ IME
├─ 音声
└─ ウィジェット
```

を利用できます。

特にゲームやGUIアプリケーションでは、

```
while true
    // 入力
    if getkey(37)
        x -= 1
    end

    // 更新
    x += 1

    // 描画
    cls()
    pset(x, y)

    // 次のフレームまで待つ
    await()
end
```

のように、`入力 → 更新 → 描画 → await()` の流れで記述できます。

# 基本方針

`Golash` では、曖昧さを減らすため、以下を特に重視しています。

* 条件式は整数（0=false、非0=true）に限定します。`true`/`false` は 1/0 の糖衣構文です。
* ビット演算は整数に限定します。
* エラーには可能な限りファイル名・行・列を付けます。
* 改行を文の区切りとして使用します。
* 配列の動作を明確に定義します。
* GUIとCUIの違いを、実行環境ではなく組み込み関数単位でも確認できるようにしています。
* 整数演算のオーバーフローはラップします（`abs(MinInt64)` のみ例外）。
* `NaN`・`±Inf` は値として存在しません（生成・変換はすべてエラー）。
* 範囲外アクセス・黙認の切り詰めはエラーに統一します。
* 再帰は深さ10000、構文ネストは1000が上限です。

サンプルプログラムについては `examples/`（落ちものパズルの作例）、言語の回帰用フィクスチャについては `testdata/parity/`、仕様の回帰確認については各テストファイルを参照してください。
